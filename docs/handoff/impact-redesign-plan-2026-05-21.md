# 후킹 강화 리디자인 기획안

작성일: 2026-05-21
브랜치: `hook/impact-v1`
보존 기준본: `baseline/editorial-v1`

## 판단

현재 버전은 정돈되어 있고 세련되지만, 클라이언트가 원하는 방향과는 감정 온도가 다르다.

클라이언트가 원하는 것은 고급 편집형 랜딩이 아니라, 광고 유입자가 들어오자마자 멈추고 읽게 되는 `강한 전단지형 랜딩`에 가깝다. 다만 닭장수후라이드의 메시지는 수익 보장, 지원금, 폐점률, 평균 매출 같은 숫자 후킹으로 가면 안 된다.

따라서 다음 버전의 핵심은 다음과 같다.

> 숫자로 자극하지 말고, 창업자의 불안과 장사 장면을 크게 보여준다.

## 새 콘셉트

### 이름

`동네에 손님이 쌓이는 치킨집`

### 톤

- 지금보다 더 직접적이다.
- 더 크고 굵게 말한다.
- 한 섹션에 3~4개의 큰 메시지를 넣는다.
- 이미지와 그래픽을 더 많이 쓴다.
- 고급스러움보다 눈에 띄는 힘을 우선한다.
- 단, 저가형/과장형 프랜차이즈 광고처럼 보이지 않게 선은 지킨다.

### 핵심 문장

```text
배달앱만 켜놓는다고
손님이 쌓이지 않습니다.
```

또는 더 강하게:

```text
광고를 꺼도
다시 오는 손님이 있어야 합니다.
```

## 디자인 방향

### 현재 버전에서 유지할 것

- 배달앱 의존 문제
- 포장 손님
- 동네 단골
- 다시 찾는 후라이드
- 내 지역 가능성 상담
- 4050 타깃을 위한 큰 글자와 명확한 CTA

### 바꿀 것

- 섹션을 차분한 설명형에서 강한 메시지 보드형으로 전환한다.
- 긴 문단을 줄이고, 큰 문장 3~4개를 먼저 보여준다.
- 이미지 한 장을 얌전히 놓는 방식보다, 사진/스티커/배지/강조 박스가 섞인 구성을 쓴다.
- BI 컬러만 쓰지 않는다.
- 특정 구간에는 빨강, 노랑, 민트, 검정 같은 강한 대비를 허용한다.
- 섹션마다 시각적 성격을 다르게 만든다.

## 안전선

아래 표현은 사용하지 않는다.

- 매출 보장
- 수익 보장
- 월 매출, 순수익, 마진율, 원가율
- 폐점률
- 지원금 액수
- 창업비 최저가
- 경쟁 브랜드 직접 비교
- `무조건`, `확실히`, `보장`, `대박` 같은 확정 표현

대신 아래 방향으로 후킹한다.

- `손님이 올까?`
- `광고비를 계속 써야 하나?`
- `배달앱 주문만 기다려도 될까?`
- `우리 동네에서 포장 손님이 생길까?`
- `혼자 또는 부부가 감당할 수 있을까?`

## 페이지 구조 제안

### 1. Hero

역할: 첫 화면에서 문제를 때린다.

메시지:

```text
배달앱만 켜놓는다고
손님이 쌓이지 않습니다.
```

큰 보조 메시지 3개:

- 광고가 멈추면 주문도 멈추는 장사
- 할인 없이는 기억나지 않는 메뉴
- 다시 올 이유가 없는 치킨집

비주얼:

- 어두운 매장/퇴근길 배경
- 큰 흰색 헤드라인
- 노란 CTA
- 화면 한쪽에 `내 동네도 가능할까?` 진단 배지

### 2. Shock Hook Block

역할: 초반 이탈을 막는 두 번째 후킹.

메시지:

```text
치킨집 창업,
맛보다 먼저 봐야 할 건 손님입니다.
```

큰 메시지 4개:

- 앱 주문만 기다리는 시간
- 광고비가 멈추면 끊기는 유입
- 포장 동선 없는 입지
- 단골 장면 없는 메뉴

비주얼:

- 빨강/검정/크림 대비
- 경고표지나 도장 같은 그래픽
- 너무 공포스럽지 않게, `체크해야 할 현실` 느낌

### 3. Scene Proof

역할: 닭장수가 보는 답을 장면으로 보여준다.

메시지:

```text
우리는 주문보다
다시 오는 장면을 봅니다.
```

큰 메시지 3개:

- 퇴근길 포장
- 주말 식탁
- 동네 단골

비주얼:

- 사진 3장 또는 AI 장면 이미지 3장
- 각 이미지 위에 큰 타이틀만 얹는다.
- 설명은 최대 한 줄.

### 4. Menu Impact

역할: 제품 설득을 더 크게 만든다.

메시지:

```text
한 번 먹고 끝나는 치킨 말고,
다음 포장이 떠오르는 후라이드.
```

큰 메시지 3개:

- 얇고 바삭한 튀김옷
- 담백하게 남는 속살
- 포장 후에도 기억되는 식감

비주얼:

- 치킨 클로즈업을 훨씬 크게 사용
- 제품 이미지 위에 짧은 키워드 배지
- 크림 배경만 쓰지 말고, 강한 포인트 컬러 섞기

### 5. Local Diagnosis

역할: 상담받을 이유를 만든다.

메시지:

```text
우리 동네도 될까요?
상담에서는 먼저 세 가지를 봅니다.
```

큰 메시지 3개:

- 포장 동선
- 반복 구매 장면
- 운영 가능 구조

비주얼:

- 지도/체크리스트/진단 리포트 느낌
- `내 지역 체크하기` CTA를 중간에 크게 배치

### 6. Founder Fit

역할: 내가 해당되는지 빠르게 판단하게 한다.

메시지:

```text
이런 분이라면
먼저 상담해볼 만합니다.
```

큰 메시지 4개:

- 작은 매장으로 시작
- 1인 또는 부부 운영
- 처음이라 순서가 필요한 창업
- 기존 매장 전환

주의:

- `누구나 가능`처럼 말하지 않는다.
- 오히려 `배달 주문만 기대한다면 맞지 않을 수 있습니다`를 짧게 넣으면 신뢰가 오른다.

### 7. Lead Capture

역할: 다시 설득하지 않고 상담 결과만 말한다.

메시지:

```text
상담 후에는
내 지역의 시작 조건이 정리됩니다.
```

큰 메시지 3개:

- 내 지역 포장 동선
- 나에게 맞는 운영 방식
- 오픈 전 확인할 준비 순서

CTA:

```text
카카오톡으로 내 지역 확인하기
```

## 이미지 활용 방향

다음 버전은 이미지 사용을 더 공격적으로 늘린다.

추천 이미지:

- 퇴근길 포장 손님 장면
- 주말 식탁 위 포장 치킨 장면
- 매장 앞 포장 대기 장면
- 주방에서 치킨을 튀기는 장면
- 지도 위에 포장 동선이 표시된 그래픽
- 상담 리포트/체크리스트 이미지
- 친근한 점주 캐릭터 또는 상담 캐릭터

AI 생성 이미지를 써도 좋은 구간:

- Hero 배경
- 장면형 섹션 이미지
- 지역 진단 그래픽
- 캐릭터/스티커성 보조 이미지

공식 제품/로고가 필요한 구간:

- 메뉴 섹션
- 로고 노출
- 브랜드 신뢰 구간

## 컬러 방향

기본:

- Navy `#142A4D`
- Gold Brown `#AB7C64`
- Cream 계열

확장:

- CTA Yellow
- Alert Red
- Deep Black
- Mint
- Warm Orange

원칙:

- 네이비만 반복하지 않는다.
- 섹션별로 포인트 컬러를 다르게 준다.
- 카카오 CTA는 노란색 중심으로 유지한다.
- 전체가 싸구려 전단처럼 보이지 않게 여백과 타이포 계급은 유지한다.

## 구현 우선순위

1. Hero 카피와 보조 메시지를 광고형으로 재구성한다.
2. Hero 아래 `Shock Hook Block`을 새로 추가한다.
3. 기존 `ProblemAnswer`를 더 큰 4개 메시지 보드로 바꾼다.
4. `SuccessScenes`를 이미지 중심의 장면 섹션으로 강화한다.
5. `MenuProof`는 치킨 이미지를 더 크게 쓰고 키워드 배지를 추가한다.
6. `LocalFitQnA`는 진단 리포트처럼 만든다.
7. 중간 CTA를 더 자주, 더 크게 배치한다.

## 한 줄 결론

다음 버전은 `세련된 브랜드 소개서`가 아니라 `광고 타고 들어온 예비창업자를 멈춰 세우는 창업 상담 랜딩`으로 가야 한다.
