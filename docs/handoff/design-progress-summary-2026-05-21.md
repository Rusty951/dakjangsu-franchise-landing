# 닭장수후라이드 가맹 랜딩 작업 정리

작성일: 2026-05-21
문서 성격: 내부 작업 정리 및 클라이언트 1차 공유 전 핸드오프

## 현재 상태

- `src/frontend`에 React + Vite 기반 랜딩페이지를 구현했다.
- 현재 페이지는 최종본이 아니라 `1차 방향성 시안`으로 보는 것이 맞다.
- 클라이언트에게는 디자인 최종 확인용이 아니라, 가맹 랜딩의 메시지 방향과 흐름 확인용으로 공유한다.
- 로컬 확인 URL은 `http://127.0.0.1:5173/` 또는 `http://localhost:5173/`이다.
- 2026-05-21 후반 작업에서 오로라사운드 레퍼런스와 비교한 뒤, 본문 톤을 더 통일하는 `Tone Lock Pass`를 적용했다.
- 이후 4050 예비 창업자 기준으로 텍스트 밀도, 글자 크기, CTA 가독성, 색상 전환 리듬을 한 번 더 조정했다.
- 최근 외부 피드백: `세련되긴 하나 너무 무난한 구성과 톤이다. 더 후킹 요소를 넣어주면 좋겠다.`
- 추가 피드백 상세 정리: `docs/handoff/client-feedback-hook-direction-2026-05-21.md`

## 핵심 방향

- 일반적인 치킨 브랜드 소개가 아니라 예비 창업자의 첫 불안인 `손님이 올까?`에서 시작한다.
- 전체 설득 흐름은 아래 구조를 따른다.
  1. 손님 문제
  2. 닭장수의 답
  3. 손님이 다시 오는 장면
  4. 팔릴 메뉴
  5. 내 동네 가능성
  6. 가맹점주 인터뷰
  7. 맞는 창업자
  8. 상담
- 실제 페이지 상에서는 7단계 PRD 흐름을 유지하되, 설득을 위해 `성공 장면`과 `점주 인터뷰` 섹션을 보강했다.
- 기존 `본사 지원` 섹션은 페이지 길이를 줄이기 위해 독립 섹션에서는 제외했고, 최종 상담 블록의 `오픈 준비 흐름`으로 역할을 흡수했다.
- 메인 CTA 문구는 `카카오톡으로 내 지역 확인하기`로 통일했다.
- 전화번호는 보조 연락 수단으로만 사용한다.

## 주요 구현 내용

### 1. 브랜드 톤 재정리

- 이삭토스트 레퍼런스의 `브랜드 소개형`, `넓은 여백`, `큰 이미지`, `절제된 문장` 방향을 참고했다.
- 오로라사운드 레퍼런스와 비교 후, `완성된 톤`을 만들기 위해 배경 종류와 CTA 문구를 더 줄였다.
- 프랜차이즈 템플릿처럼 보이는 카드, 배지, 과한 그림자, 과한 설명문을 줄였다.
- 브랜드 가이드 기준 색상을 중심으로 재정리했다.
  - Navy: `#142A4D`
  - Gold Brown: `#AB7C64`
  - Mint/Rose Pink는 거의 쓰지 않고 보조 포인트로 제한
- 공식 로고는 가이드북 PDF에서 추출한 임시 PNG를 사용했다.
  - 파일: `src/frontend/public/brand/dakjangsu-logo-full-color.png`
  - 최종 납품 전 원본 AI/EPS/SVG 로고로 교체 권장

### 1-1. Tone Lock Pass

2026-05-21 후반에 아래 작업을 추가 적용했다.

- 본문 섹션 배경을 거의 `크림 톤` 하나로 통일했다.
- 마지막 `LeadCapture`만 네이비 전환 블록으로 남겼다.
- 6번 본사 지원 섹션의 중간 네이비 박스를 제거해, 최종 CTA 블록만 강한 전환 영역으로 보이게 했다.
- 주요 CTA 문구를 `카카오톡으로 내 지역 확인하기`로 통일했다.
- `내 동네 가능성 보기`만 중간 소프트 CTA로 유지했다.
- 메뉴/지역/인터뷰 이미지 필터를 조금 맞춰 네이비/골드 계열 톤 차이를 줄였다.
- 현재 의도는 더 꾸미는 것이 아니라, 섹션 간 시각 언어를 줄여 하나의 브랜드 톤처럼 보이게 하는 것이다.
- 40대 이상 예비 창업자도 모바일에서 읽기 쉽도록 본문, 리스트, CTA, 모바일 하단 CTA의 글자 크기와 대비를 올렸다.

### 3. 히어로

- 줄 서서 기다리는 사람 이미지를 히어로에 적용했다.
- 메시지는 `배달앱만으로는 손님이 쌓이지 않습니다.`로 정리했다.
- CTA는 `카카오톡으로 내 지역 확인하기`로 통일했다.
- 히어로 내부의 불필요한 상단 설명 라인은 제거했다.

### 4. 손님 문제 / 성공 장면

- 히어로에서 배달앱 문제를 직접 말하므로, 다음 문제 제기 섹션은 `첫 주문보다 다시 오는 손님.`으로 역할을 바꿨다.
- 이후 `손님이 다시 오는 장면.` 섹션을 추가해 장면형 설득을 보강했다.
- 세 장면은 원형 이미지 병렬 구조로 정리했다.
  - 퇴근길 포장
  - 주말 재방문
  - 동네 단골

### 5. 메뉴 / 지역 가능성

- 메뉴 섹션에는 앞치마를 입은 사람이 치킨을 들고 있는 브랜드형 이미지를 사용했다.
- 메뉴 섹션은 네이비 배경에서 크림 배경으로 변경해, 강한 네이비 전환은 히어로와 마지막 상담 영역 중심으로 줄였다.
- `한 번 팔리는 메뉴보다, 다시 찾는 메뉴` 메시지를 중심으로 정리했다.
- 지역 가능성 섹션은 실제감 있는 튀김 클로즈업 이미지를 크게 사용하고, 그 위에 핵심 문장을 얹었다.
- 기존의 과한 라인과 Q&A 느낌을 줄이고, `볼 것은 세 가지입니다.` 구조로 압축했다.

### 6. 점주 인터뷰

- 창업 결정 직전에 신뢰를 만드는 섹션으로 `OwnerInterview`를 추가했다.
- 현재 이미지는 실제 영상이 아니라 예시 이미지다.
- 내부 제작용 문구는 제거했고, 화면에는 `인터뷰 영상`, `90초 구성` 같은 클라이언트 공유용 임시 문구만 남겼다.
- 한 줄 인터뷰는 임시 문구다.
  - `오픈 전에 봐야 할 순서가 분명해졌어요.`
  - `혼자 운영해도 본사가 옆에 있는 느낌이었습니다.`
- 클라이언트 공유 시 이 섹션은 실제 점주 영상과 실제 후기 문구로 교체해야 한다고 안내하는 것이 좋다.

### 7. 맞는 창업자 / 상담 전 확신

- 5번은 체크리스트형 자기 선별 섹션으로 정리했다.
- 독립 본사 지원 섹션은 제거하고, 최종 상담 섹션의 `오픈 준비 흐름` 항목으로 흡수했다.
- 5~6번은 `상담 전 확신` 흐름으로 본다.
  - 5번: 내가 이 브랜드와 맞는가
  - 6번: 내 지역, 운영 방식, 오픈 준비 흐름을 상담에서 확인하는가
- 아직 최종 설득력은 실제 운영 장면/점주 인터뷰 자료가 들어가야 더 올라간다.

### 8. 상담 / 푸터

- 6번 상담 영역은 네이비 CTA 블록으로 유지했다.
- 상담 CTA는 카카오톡으로 통일했다.
- 리드 폼은 제거하고, 상담에서 확인하는 세 가지를 보여준다.
  - 내 지역 가능성
  - 운영 방식 적합성
  - 오픈 준비 흐름
- 푸터는 7번 상담 섹션과 구분되도록 크림 배경으로 분리했다.
- 푸터에는 회사 정보와 유튜브/블로그/인스타그램 아이콘을 넣었다.

### 9. 오른쪽 플로팅 메뉴

- 데스크톱 전용으로 작은 플로팅 메뉴를 추가했다.
- 구성:
  - TOP
  - 대표전화 `1588-2287`
  - 카카오 상담
  - 가맹 안내
- 태블릿 이하에서는 숨긴다.
- 모바일에서는 하단 고정 카카오 CTA만 노출한다.
- 플로팅 메뉴는 편의성은 있지만, 너무 크면 프랜차이즈 템플릿 느낌이 살아날 수 있으므로 현재보다 더 키우지 않는 것이 좋다.

## 현재 평가

- 내부 리뷰용: 가능
- 클라이언트 1차 방향성 공유용: 가능
- 최종 디자인/개발 완료본: 아직 아님

현재 완성도 판단:

- 구조/설득 흐름: 약 84점
- 실제 사람 기준 디자인 완성도: 주니어 후반~미드레벨 초입의 1차 시안 수준
- 클라이언트에게 보여줄 수 있는 1차 시안 수준
- 90점 이상으로 올리려면 실제 신뢰 자산과 모바일 최종 점검이 필요

## 남은 작업

우선순위 높은 작업:

1. 실제 점주 인터뷰 영상 또는 썸네일 교체
2. 실제 점주 한 줄 후기 문구 확정
3. 실제 매장/제품/포장 사진 추가 확보
4. 모바일 390px 기준 전체 캡처 검토
5. 카카오톡 상담 URL 확정 및 연결
6. 전화번호, 개인정보처리방침, 회사 정보 최종 확인
7. 임시 이미지/예시 문구 제거 또는 클라이언트 확인 후 유지 여부 결정

새로 받은 피드백 기반 작업:

1. 현재 톤은 세련되지만 무난하므로, 후킹 요소를 추가한다.
2. 히어로 직후에 짧은 문제 후킹 바 또는 선언형 문장 블록을 검토한다.
3. `우리 동네에도 될까요?` 섹션을 더 자가진단형으로 강화한다.
4. 중간부에 한 줄 선언형 카피 블록을 추가할지 검토한다.
5. 단, 매출/수익/창업비/폐점률/숫자 보장성 후킹은 금지한다.
6. BI 색상 외 보조 컬러와 AI 생성 이미지/캐릭터/장면형 그래픽 활용도 열어둔다.
7. 섹션마다 3~4개 핵심 메시지를 크게 보여주는 구성을 검토한다.

다음 디자인 개선 포인트:

- 이미지 퀄리티 편차 줄이기
- 플로팅 메뉴가 너무 기능적으로 보이지 않는지 재검토
- 5~6번 섹션에 실제 운영 장면을 더 넣어 초보 창업자의 확신 보강
- CTA 직전의 상담 효용을 더 선명하게 만들기
- 모바일에서 긴 헤드라인 줄바꿈과 CTA 반복 위치 점검

## 클라이언트 공유 시 추천 설명

클라이언트에게는 아래 톤으로 공유한다.

```text
닭장수후라이드 가맹 랜딩페이지 1차 방향성 시안 공유드립니다.

이번 시안은 디자인 최종본이라기보다,
```
