# Antigravity Frontend Brief

## Task

Build the frontend for a franchise lead landing page. Prioritize conversion, mobile readability, and brand trust.

## Ownership

Antigravity owns:
- layout
- responsive UI
- visual hierarchy
- components
- interaction polish
- media placement

Codex owns:
- backend/API
- form validation contract
- tracking contract
- code review and debugging

## Frontend Stack

- Use React + Vite + Vanilla CSS.
- Build inside `src/frontend`.
- Split sections into maintainable components such as Hero, Problem/answer, Menu proof, Local fit Q&A, Founder fit checklist, HQ support, and Lead capture.
- Do not introduce Tailwind, UI kits, CSS-in-JS, or another frontend framework unless the project owner approves it.
- Do not use the Vanilla HTML/CSS/JavaScript-only option for this project.

## First Screen

Must immediately signal:
- this is a franchise landing page
- the customer problem is "손님"
- the answer is a neighborhood fried-chicken model based on packaging and repeat customers
- the primary action is KakaoTalk consultation

## Required Sections

1. Hero with CTA
2. Problem/answer
3. Menu proof
4. Local fit Q&A
5. Founder fit checklist
6. HQ support
7. Lead capture

## Visual Direction

- Use real brand/product/store imagery when available.
- Prefer fried chicken, packaging, storefront, cooking, and owner-interview visuals.
- Avoid generic stock-feeling food layouts.
- Keep the page practical and conversion-focused, not a decorative brand manifesto.
- Mobile CTA must stay easy to reach.

## Brand Tokens

- Navy: `#142A4D`
- Gold Brown: `#AB7C64`
- Mint: `#73C6C6`
- Roze Pink: `#EE806D`
- Font: Nanum Square, Pretendard, system sans fallback.

## Do Not

- Do not put unconfirmed numbers into the UI.
- Do not use sales/profit guarantee language.
- Do not make phone the primary CTA unless the project owner changes the strategy.
- Do not recolor or distort the logo.
