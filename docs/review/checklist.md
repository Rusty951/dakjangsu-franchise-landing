# 검수 기준

- 요청 범위의 모바일과 데스크톱 화면에서 본문, 캐릭터, 버튼이 겹치지 않고 가로 넘침이 없는지 확인합니다.
- 링크 목적지, 키보드 포커스와 FAQ 접기/펼치기를 확인합니다.
- 혜택 금액과 조건 확인 중 표기를 보존합니다.
- 실제 문의를 보내지 않고 검토 양식과 API 보호를 확인합니다.
- 변경에 필요한 `npm run lint`, `npm test`, `npm run build`를 실행합니다.
- 샘플 배포는 빌드와 함수 모두 `VITE_REVIEW_ONLY=true`인지 확인합니다.
- 배포 완료 시 공개 주소의 실제 화면과 링크를 확인합니다.
