# 검수 기준

- 요청 범위의 모바일과 데스크톱 화면에서 본문, 캐릭터, 버튼이 겹치지 않고 가로 넘침이 없는지 확인합니다.
- 링크 목적지, 키보드 포커스와 지원 조건 접기/펼치기를 확인합니다. FAQ 답변 3개는 항상 보이며 별도 닫기 버튼이 없어야 합니다.
- 혜택 금액과 조건 확인 중 표기를 보존합니다.
- 모바일 지원은 오픈 740만원, 주방 500만원, 로열티 면제와 월 최대 100만원 물류 크레딧 네 장이다. 로열티와 물류는 분리돼야 한다. 모든 지원 장면에서 닭장수 캐릭터가 보이며 모바일 메뉴는 6개, 데스크톱 메뉴는 기존 8개다. 모바일 8번 상담 장면은 없고 최종 상담 영역은 남아 있어야 한다. 모바일과 데스크톱 전환 시 없는 장면의 인덱스를 참조하지 않아야 한다.
- 모바일 6번은 닭장수가 숫자를 들어 올리고 받쳐 든 뒤 원래 큰 구도로 정착한다. 월 최대와 크레딧 단위가 들기 중에도 보이고, 완료 후 조건과 링크가 돌아와야 한다. 화면 전환 후 내용, 메뉴와 캐릭터의 장면 번호가 일치해야 한다.
- 모바일 첫 화면은 390×664, 390×844, 402×874 CSS px에서 캐릭터 원본 전체가 첫 뷰포트 안에 들어오는지 확인합니다. 2,800만원과 0원은 한 화면에 함께 담고 캐릭터 장면은 같은 중앙 영역에 맞추며 반복 지원 설명 블록은 모바일 첫 화면 아래에 없어야 합니다. 도입의 계산 가정과 면제 조건 표기, 이후 지원 조건 안내는 유지합니다.
- 실제 문의를 보내지 않고 검토 양식과 API 보호를 확인합니다.
- 변경에 필요한 `npm run lint`, `npm test`, `npm run build`를 실행합니다.
- 샘플 배포는 빌드와 함수 모두 `VITE_REVIEW_ONLY=true`인지 확인합니다.
- 배포 완료 시 공개 주소의 실제 화면과 링크를 확인합니다.
