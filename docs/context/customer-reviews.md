# 고객 리뷰 구간의 입력 근거

2026-10-27 대표의 후라이드 극찬 리뷰 선정과\
“인생 치킨 등극” 추가 요청을 반영한\
`RebrandCustomerProof.jsx`의 원문과 자산 연결입니다.\
표시 문구는 원문 발췌 그대로 유지하며, 예외는 아래 리뷰 절에 적습니다.

2026-10-29 대표 요청으로 각 리뷰 아래에 매장명과\
닉네임 앞 두 글자 뒤에 `**`를 붙여 표시합니다.\
예를 들어 “읍내점 Ki**” 형식입니다.\
원문 확인은 아래 플레이스 출처를 따르며\
날짜와 방문 횟수는 화면에 표시하지 않습니다.

각 `blockquote`의 `cite`에는 원문 플레이스 주소를 남깁니다.\
“인생 치킨 등극”의 주문 메뉴 맥락은 이 문서에 보존하며,\
대표의 후속 요청으로 카드의 메뉴 설명은 표시하지 않습니다.\
해당 발췌는 브랜드에 대한 평가로 사용하며\
기본 후라이드를 주문한 후기라고 설명하지 않습니다.

## 리뷰

2026-11-06 대표 요청으로 서산 지점 위주였던 6개를 지역이 다른 6개로 교체했습니다.\
네이버 플레이스 공개 방문자 리뷰 전수 수집(44개 지점, 8,395개)에서\
시그니처 후라이드에 대한 칭찬을 지점과 칭찬 포인트가 겹치지 않게 골랐고,\
"옛날통닭" 표현이 들어간 리뷰는 대표 결정으로 제외했습니다.

원문 안에서 이어진 부분만 발췌하고 문구는 바꾸지 않았습니다.\
예외로 한솔점 원문의 "뛰긴"은 대표 요청으로 "튀긴"으로 고쳤습니다.\
아래 날짜는 개별 방문일이며 화면에는 표시하지 않습니다.\
지점별 개인 경험이며 매출, 전체 지점의 동일한 품질이나 재방문율을 뜻하지 않습니다.
