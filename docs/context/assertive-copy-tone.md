# Assertive Copy Tone

## Purpose

Use this document when rewriting visible landing copy without changing the current page structure.

The goal is not to add more explanation. The goal is to make each section hit harder.

## Core Direction

Keep the structure.
Change the voice.

The copy should feel like a franchise ad poster, not a strategy memo.

Target voice:

- short
- blunt
- declarative
- rhythmic
- visually punchy
- safe from unsupported revenue or success claims

## Main Rule

Avoid polite explanatory endings:

- `합니다`
- `입니다`
- `확인합니다`
- `생각합니다`
- `제공합니다`

Prefer slogan-like endings:

- `다`
- noun endings
- clipped phrases
- line breaks that create rhythm

Example:

Bad:

```text
배달앱 주문마다 비용이 붙습니다.
```

Better:

```text
주문은 늘었는데
남는 돈은 줄어든다
```

Better:

```text
팔릴수록 빠져나가는 비용
치킨집은 숫자부터
```

## Borrowed Rhythm

Reference-style rhythm:

```text
문제 던짐
크게 단정
비주얼로 때림
마지막에 답은 우리
```

Do not copy competitor claims such as revenue guarantees or hard benefit promises.
Borrow only the sentence rhythm and confidence.

## 닭장수 Core Message

Best main direction:

```text
배달앱만 보는 치킨집 말고
동네에서 다시 팔리는 치킨집

답은 닭장수후라이드
```

Alternate:

```text
한 번 팔고 끝나는 치킨 말고
다시 찾는 후라이드

닭장수후라이드
```

Alternate:

```text
손님이 걸어와야 매장
다시 사러 와야 장사

닭장수후라이드
```

## Section Tone Map

### Hero

Current role: first impression.

Use:

```text
배달앱만 보는 치킨집 말고
동네에서 다시 팔리는 치킨집
```

```text
한 번 팔고 끝나는 치킨 말고
다시 찾는 후라이드
```

```text
오늘 주문보다
다음 방문
```

Avoid:

```text
포장과 홀 손님까지 생각한 닭장수후라이드 창업
```

This is accurate, but too explanatory for the desired tone.

### Problem

Current role: name the founder's anxiety around delivery-app dependency.

Use:

```text
주문은 늘었는데
남는 돈은 줄어든다
```

```text
배달앱 매출만 보면
장사 구조를 놓친다
```

```text
팔릴수록 빠져나가는 비용
숫자부터 봐야 한다
```

```text
배달앱만으론
부족하다
```

Avoid:

```text
공개 요금제 기준 비용 계산
```

This can remain as small supporting UI text, but not as the main emotional copy.

### Answer

Current role: shift from delivery-app anxiety to takeout, hall, and neighborhood repeat visits.

Use:

```text
배달앱 밖에서도 팔려야
진짜 매장
```

```text
포장 손님 붙고
홀 손님 머물고
동네 손님 다시 온다
```

```text
닭장수는 주문보다
재방문을 본다
```

```text
손님이 걸어와야 매장
다시 사러 와야 장사
```

### Menu Proof

Current role: make the product reason sharp.

Use:

```text
기억나는 바삭함
다시 오는 손님
```

```text
한 번 먹고 끝나는 맛 말고
다시 생각나는 후라이드
```

```text
얇게 바삭하고
고소하게 남는다
```

Only use taste details supported by confirmed brand material:

- 특제 파우더
- 얇은 튀김
- 깨끗한 기름 관리
- 겉바속촉
- 고소함

### Local Fit / Owner Check

Current role: make consultation feel like a practical check, not a soft inquiry.

Use:

```text
창업은 감이 아니라 조건
```

```text
열 수 있는 자리보다
버틸 수 있는 조건
```

```text
지역 보고
운영 보고
비용 보고
시작
```

```text
내 동네에 닭장수
맞는 자리부터 확인
```

### Final CTA

CTA stays Kakao-only.

Use:

```text
고민보다 먼저
지역 확인
```

```text
내 동네에 닭장수
가능한지 먼저 확인
```

```text
카카오톡으로
지역부터 확인
```

Avoid long explanation before the CTA.

## Safe Aggression

Good aggression:

```text
배달앱만 믿는 치킨집, 위험하다
```

```text
주문이 많아도 남지 않는 장사
```

```text
동네에서 다시 찾지 않으면
오래가기 어렵다
```

Avoid unsafe aggression:

```text
무조건 성공
```

```text
월 매출 보장
```

```text
흑자전환 보장
```

```text
폐점 걱정 없음
```

```text
업계 최저 창업비
```

## Rewrite Checklist

Before applying copy, check:

- Does it sound like a poster, not a paragraph?
- Can the line be understood in one glance?
- Did we remove `합니다` and `입니다` where possible?
- Does the line avoid unsupported revenue, profit, cost, store-count, or success claims?
- Does the line point back to one idea: delivery dependency is weak, neighborhood repeat visits are stronger?
- Does the CTA stay Kakao-only?

## Tone Summary

Not:

```text
친절한 안내문
```

Use:

```text

```
