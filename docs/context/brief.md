# 현재 프로젝트 기준

닭장수후라이드 창업 상담용 리브랜딩 랜딩페이지입니다. 기준 경로는 `/?concept=rebrand`입니다.

## 구성

1. 창업 지원 합산 예시, 리브랜딩 설명과 캐릭터 지원 안내 8장면
2. 매장 외관과25평형 실내 디자인 시안
3. 부천중동점, 강남세곡점, 서울잠실점, 서울문정점 인터뷰
4. 기본 펼침 FAQ3개와 별도 지원 조건 안내
5. 상담 양식과 창업 문의1588-2287
6. 유튜브, 페이스북, 인스타그램, 블로그 순서의 하단 링크

카카오톡 버튼은 헤더 아래 오른쪽 상단에 고정합니다. 첫 화면 캐릭터는2.4초의 연속 손동작을 한 번 재생합니다. 다른 장면의 강약과 현재 이미지 구성을 유지합니다.
4번 오픈 지원 장면은 같은 캐릭터 이미지 한 장에서 안내 손만 작게 움직인 뒤 원래 포즈로 돌아오는 2.4초 모션을 사용합니다. 포즈 교체와 손 이미지 중첩을 피하고 기존 캐릭터 크기와 배치를 유지합니다.
6번 로열티 장면도 같은 이미지 한 장으로 안내 손만 작게 움직입니다. 몸통과 다른 포즈의 팔을 합성하지 않고, 기존 크기와 배치를 유지합니다.
8번 상담 장면은 손짓을 반복하지 않고 같은 이미지가 오른쪽에서 0.8초 동안 짧게 들어와 멈춥니다. 상담 버튼을 가리지 않으며 반복 재생하지 않습니다.

2026-10-08 회의 반영: 첫 화면 합산 예시는 오픈 740만원 + 주방 500만원 + 물류 크레딧 1,560만원 = 2,800만원 상당입니다. 물류는 첫 12개월 월매출 3,000만원, 다음 12개월 월매출 4,000만원을 가정합니다. 가맹비와 교육비 면제 440만원은 오픈 지원에 이미 포함되며 로열티 면제는 합산에서 제외합니다. 24개월은 검토용 계산 가정이며 실제 지원 기간과 적용 조건은 확인 중입니다. 현금 지급이나 전체 창업비0원으로 표현하지 않습니다. 점주 발언은 해당 점주의 개별 경험이며 생성된 인터뷰 커버는 원본 일러스트를 바탕으로 만든 이미지입니다.

검토 사이트: https://dakjangsu-client-sample.vercel.app/?concept=rebrand
샘플 배포에는 빌드/함수 환경 모두 `VITE_REVIEW_ONLY=true`가 필요합니다. 공식 사이트와 샘플 프로젝트의 배포 대상을 혼동하지 않습니다.

2026-10-08 수정 범위는 혜택 계산, 모바일 첫 화면, 두 번째 리브랜딩 설명입니다. 후속 공간 이미지와 전체 검수 일정은 클라이언트 `C001_닭장수후라이드/tasks.md`에서 관리합니다.

디자인 기준: 기존 첫 화면의 좌우 색상 분할, 큰 합산 금액과 가맹비, 교육비, 첫 2년 로열티 0원 안내, 중앙 캐릭터와 기존 버튼 스타일을 유지합니다. 지원 구성을 기존 화면 안에 추가하며 새 브랜드 장면은 기존 지원 장면의 글자와 캐릭터 배치 규칙을 재사용합니다.
첫 화면에서는 지원 항목을 되풀이하는 소개문과 하단 설명을 제거합니다. 면제 포함 관계와 로열티 제외는 오른쪽에서 한 번 안내하고, 월매출 가정과 조건 확인 중 표기는 보존합니다. 데스크톱의 두 금액은 같은 높이에서 시작합니다.
