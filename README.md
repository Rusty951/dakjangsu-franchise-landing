# 닭장수후라이드 가맹 랜딩페이지

닭장수후라이드 가맹 상담 전환을 위한 랜딩페이지 프로젝트입니다.

## Role Split

- Antigravity: frontend design, layout, responsive UI, interaction polish.
- Codex: planning, backend/API, lead form, tracking, code review, debugging, QA.

## Structure

```txt
AGENT.md                         compact agent rules
AGENTS.md                        compatibility entry
GEMINI.md                        Antigravity entry
docs/context/brief.md            compact product context
docs/context/source-map.md       source file and URL map
docs/handoff/                    Antigravity frontend brief
docs/backend/                    API contract and backend notes
docs/review/                     code review and QA checklist
references/source-pdfs/          copied source PDFs
public/assets/                   brand/photos to be added
src/frontend/                    frontend implementation area
src/backend/                     backend/API implementation area
tests/                           tests
```

## Start

Open this folder in Antigravity or Codex. First read `AGENT.md`, then `docs/context/brief.md`.
